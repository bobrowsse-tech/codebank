Color: use theme variables, never hex

The mock uses a dark sample palette. In the extension every color resolves from a VS Code variable, so light and high-contrast themes work with no extra code.
--vscode-editor-backgroundPage and panel background
--vscode-sideBar-backgroundCards, sidebar, status strip
--vscode-foregroundBody text
--vscode-descriptionForegroundSecondary and meta text
--vscode-textLink-foregroundLinks
--vscode-button-backgroundPrimary button, one per screen
--vscode-list-activeSelectionBackgroundSelected row
--vscode-list-hoverBackgroundRow hover
--vscode-badge-backgroundTags and counts
--vscode-editorWarning-foregroundStale, drift, warnings
--vscode-errorForegroundSecret found, errors
--vscode-testing-iconPassedClean scan, done
--vscode-panel-borderAll dividers and card borders
--vscode-input-backgroundText fields
--vscode-quickInput-backgroundSearch pick, toasts

Type, space, shape

Text: var(--vscode-font-family) 13px / 20px
Small: 12px / 18px, meta and hints
Heading: 18px / 26px, weight 600, one per panel
Code: var(--vscode-editor-font-family)
Spacing steps: 4, 8, 12, 16, 24, 28
Radius: 2 inputs, 4 buttons, 6 cards, 10 tags
Row heights: 22 list, 48 pick, 26 and 30 buttons
